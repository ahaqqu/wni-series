## Rules

- Dates and sources are part of the evidence. Do not delete a source because it is inconvenient.
- The refresh wins over older findings on volatile facts (fares, station closures, schedules, congestion). The live-data/Mayar file wins on provider fees, payment terms, and live-data feasibility.
- Qualitative/geometry findings remain useful unless contradicted.
- Content shipped to players must be re-validated in the content pipeline, not copied blindly from research.
- No personal data, scraped user content, or copyrighted map tiles.
