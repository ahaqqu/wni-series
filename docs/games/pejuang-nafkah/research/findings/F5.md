## Route templates (for game economy / timers)

### A. Bintaro → SCBD / Sudirman / Dukuh Atas

**A1. Motor → KRL → walk (canonical Pejuang Nafkah)**
- Home → Pondok Ranji or Jurangmangu (ojek/parkir motor, 5–12 min)
- KRL Rangkasbitung → **Tanah Abang** (13–15 km rail, 18–28 min peak) **or** ride through to Kebayoran/Palmerah
- If destination SCBD: transfer Tanah Abang → (Cikarang loop) → Sudirman, **or** ojek/TJ from Tanah Abang (~10–20 min)
- Walk / ojek last mile into SCBD (10–20 min)
- **Budget:** KRL 3k + ojek 2×10–15k + park 3–5k ≈ **Rp 25–45k one way**
- **Time peak:** 55–75 min; off-peak 40–55 min
- **Depart for 08:30 office:** leave 07:00–07:15

**A2. Full motor via Pondok Indah / JORR Veteran–Ulujami**
- ~12–22 km road depending on sector; peak 60–90 min
- Fuel ~Rp 8–15k + park SCBD Rp 5–15k + optional JORR Gol I Rp 16k (if toll used)
- **Fail:** Ulujami merge macet, rain, parking full in SCBD

### B. BSD City → SCBD / Sudirman

**B1. BSD Link → Cisauk → KRL → Tanah Abang → Sudirman/ojek**
- BSD internal → Cisauk skybridge (10–20 min including wait)
- Cisauk→Tanah Abang 26.1 km, ~30–40 min peak; fare ≈ Rp 4,000
- Tanah Abang→Sudirman transfer or ojek to SCBD
- **Budget:** BSD Link (often free/cheap for residents) + KRL 4k + last mile 10–20k
- **Time peak:** 70–100 min; leave 06:45–07:00 for 08:30

**B2. Motor via Jakarta–Serpong Tol / JORR**
- ~28–40 km; peak 75–120 min
- Tol Gol I segments + fuel + SCBD park ≈ **Rp 35–70k**
- **Fail:** Serpong–Ulujami queue, accident on Tol Serpong

### C. Depok → SCBD / Sudirman / Dukuh Atas

**C1. Ojek/angkot → Depok/Depok Baru KRL → Manggarai → Sudirman**
- Depok→Manggarai ~22.6 km rail (33.3−10.7), 35–50 min peak
- Transfer Manggarai (busiest hub) or through-train to Sudirman
- Last mile Sudirman→SCBD walk 10–15 min / MRT 1 stop / TJ
- Fare ≈ Rp 4,000 KRL + first/last mile
- **Time peak:** 75–110 min; leave **06:30–06:50** for 08:30
- **Fail:** Manggarai crush, Ciliwung flood delays, Citayam level-crossing incidents

**C2. Motor via Jagorawi / Depok–Antasari**
- ~35–50 km; peak 90–150 min (very volatile)
- Higher fuel + toll; only rational for late-night or reverse commute

### D. Bekasi → SCBD / Sudirman / Dukuh Atas

**D1. Ojek/Trans Patriot → Bekasi KRL → Sudirman / BNI City**
- Bekasi–Sudirman rail ~30–35 km; 40–60 min on-train peak
- Fare ≈ Rp 4,000–5,000
- Dukuh Atas cluster (Sudirman / BNI City / Dukuh Atas BNI MRT-LRT-TJ) is the right alight for SCBD towers
- **Time peak:** 70–100 min; leave 06:30–06:50
- **Fail:** loop-direction confusion (full vs half racket), feeder that ends at Angke/Manggarai instead of Sudirman

**D2. Motor via Tol Becakayu / JORR Cikunir**
- ~25–35 km; peak 70–110 min
- Cikunir interchange is the classic jam node
- Fuel + toll + park ≈ **Rp 30–60k**

## Gameplay implications (route design, timers, economy) — max 8

1. **Two-layer economy:** KRL/TJ are dirt-cheap (Rp 3–5k legs) but demand time + crowding stress; ojek/toll are expensive but can save 15–40 min. Player's daily wage must make the trade-off feel real.
2. **Departure window mechanic:** hard office start 08:30/09:00; each corridor has a "safe leave-by" and a "risky leave-by". Missing the safe window forces ojek surge or lateness.
3. **Handoff micro-games:** motor park → platform, Tanah Abang transfer, Manggarai crush boarding, Cisauk skybridge, SCBD last-mile walk. Each has a small time cost and a failure state (missed train, wrong headboard).
4. **Train pattern wrongness:** short-turn trains (Serpong / Parung Panjang / Tigaraksa / Bekasi / Angke) — boarding the wrong one is a classic Pejuang Nafkah mistake and should be a fail mode, not just a dialog.
5. **Rain event:** multiplies ojek wait/price, slows motor, floods low roads; KRL becomes the "correct" choice — teaches mode shift under stress.
6. **Toll vs surface:** JORR/Tol Gol I Rp 16k-class charges vs free macet surface roads — pure time-vs-money choice with random accidents on toll.
7. **Weekly budget pressure:** Rp 25–70k/day × 22 days is a meaningful slice of UMR/entry salary; show a running "transport cost vs gaji" meter.
8. **Free trial scope:** ship Bintaro↔Tanah Abang/Palmerah (Rp 3,000, 3–13 km, shuttle ojek) as the teaching loop; full map unlocks BSD/Depok/Bekasi corridors and Manggarai transfer chaos.
