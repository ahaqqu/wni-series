# artifacts

Generated evidence for phase gates. Most contents are gitignored.

```text
artifacts/verification/<phase>/<YYYY-MM-DD>/
  report.md       # committed summary
  checklist.md    # committed sign-off
  screenshots/    # local/CI only
  video/
  traces/
  performance/
  security/
  payment/
  db/
```

See [docs/verification/README.md](../docs/verification/README.md) for the evidence contract. Redact emails, tokens, full IPs, cookies, and personal data before committing a summary.
