# data/raw

Raw source extracts live here. Contents are gitignored by default.

When adding a source:

1. Record it in the content source registry (URL, retrieval date, licence, confidence).
2. Prefer a small, reproducible extract over a full dump.
3. Do not commit personal data, real-time user traces, or copyrighted map tiles.
4. OSM extracts require attribution and ODbL compliance.
5. Large files belong in Git LFS or R2 with a checksum and documented retrieval script.
