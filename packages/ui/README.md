# packages/ui

**Status:** planned — seed in Phase 0, used from Phase 1.

Shared design system for the platform and games:

- CSS tokens (colour, type, spacing, motion, safe areas)
- accessible React primitives (button, dialog, tabs, field, toast)
- transit-signage components (route strip, station chip, ETA board)
- report-card and share-card primitives
- motion wrappers that respect reduced motion

Rules: WCAG 2.2 AA, 44 px touch targets, no colour-only signals, no bundled fonts, no business logic, no API calls.
